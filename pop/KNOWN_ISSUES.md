- **影響** … 遊ぶ人から何がどう見えるか
- **存在範囲** … 現行版にもあるのか、ポップ版だけか
  （`diff -r --exclude=.git --exclude=node_modules --exclude=pop . pop` で確かめる）

## オンラインCPUの呼び名

- **発生箇所** … オンライン待機画面から開始した卓の相手名（`web/src/net/OnlineTable.tsx`）。
- **再現手順** … ローカルで server と web を起動 → ONLINE → 呼び名を入力 → CRIAR → CHAMAR A CPU。
- **影響** … 日本語でも `Zé Navalha` / `Dona Rosa` / `O Fantasma` などの旧世界観の名前が表示され、単機版の旅の連れと揃わない。
- **存在範囲** … 旧名の供給元となる server / protocol は現行版と差分ゼロ。リスキン済み単機版との不一致は pop で顕在化。サーバーは変更していない。

## 変数を使わない旧配色

- **発生箇所** … `web/src/styles.css` の `.intro__panel` など、色を直接指定した背景・罫線。
- **再現手順** … 日本語のイントロまたは旅の支度画面を開き、パネル背景と外側の藍色背景を比較する。
- **影響** … `:root` の配色は夜空へ変わったが、パネルの茶色・従来の金色の一部は残る。
- **存在範囲** … 直接指定は現行版から存在。pop は計画の段階1どおり `:root` と theme-color の値のみ変更し、ほしの図像以外の直接指定を変更していない。
